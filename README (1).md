# Données brutes

**Fichier :** `T10YIE.csv` (colonnes `observation_date`, `T10YIE`)
**Source :** FRED, Federal Reserve Bank of St. Louis, série T10YIE.

## Procédure de téléchargement
1. Ouvrir https://fred.stlouisfed.org/series/T10YIE
2. Cliquer sur « Download », puis choisir « CSV (data) ».
3. Enregistrer le fichier sous `data/raw/T10YIE.csv`.

Le fichier utilisé couvre du 2003-01-02 au 2026-11-06 (6 222 lignes, 255 valeurs manquantes correspondant à des jours fériés).
Vérifier la licence et les conditions d'usage de FRED avant redistribution ; le fichier peut sinon être retéléchargé par la procédure ci-dessus.
